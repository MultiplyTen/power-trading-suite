# 复盘与调参项目

可独立复制的第三个Python项目。Python3.9+，安装 `requirements.txt` 后运行 `python main.py`。配置全部来自本目录 `config.yaml`，路径相对本目录，与启动工作目录无关。

`project_paths.load_forecast` 和 `project_paths.coefficient` 指向前两个项目；`exchange_dir`存放不可变预测快照。套件版本的前两个项目会输出带配置快照的发布清单，复盘自动读取，不能用当前参数补造旧发布时参数。

## 命令

- `python main.py init`：首次明确初始化对账库；已有库只检查，不覆盖。
- `python main.py`：导入预测、回填实际、按D−5限制复盘、回测候选、生成日报/周报/月报及建议，不改前置配置。
- `python main.py apply`：人工确认后执行，采纳最新建议文件保留的条目。双配置自动备份，检查旧值和文件哈希，拒绝过期或改写证据。
- `python main.py rollback`：还原最近一次apply之前的两个配置，历史日志保留。调整后又被人工编辑时拒绝覆盖。

选择性应用：先删除 `output/suggestions_YYYYMMDD.yaml` 中不需要的条目，再执行apply。只可删除；改新值或证据必须重新回测。默认每次最多提出一个变更，以避免未验证的参数组合。

实际Excel为 `目标时刻,实际负荷` 及 `目标时刻,日前价格,实时价格`；支持 `日期,小时` 起点0—23，价格可分日前/实时sheet配`价格`列。可选可用时间列 `available_time`/`可用时间`。缺失留缺失，负荷为0不算MAPE但保留其他指标，价格可以为负。实际值缺失、未到D+5或发布时间晚于复盘时点，均标记待复盘。

实际值D+5才能得到，而明日预测在D−1发布，因此候选回测要求前置模型至少D−6观测滞后。实际值存在修订版本、到达更晚或前置训练数据与对账值不一致时，停止相关建议，不能拿最新值冒充历史已知值。

最近30个完整日按前20天选候选、后10天验证；目标任务按归因短板决定，风控/超参/特征/模型插槽都扫描。两段改善均至少5%才形成建议，后10天失败不会再挑第二名。没有合格建议时文件保持空列表，apply不改配置。

当前输入原始发布时间、价格口径与单位尚未全部认证，所以建议只能应用到研究配置。正常运行没有自动apply。收益只是在实际负荷全按日前价结算基准上的差额，额外偏差费需要补充正式规则参数。

默认 `import_research_replay: true` 为展示研究示例：负荷来自前置负荷模型历史滚动结果，价格来自价格模型滚动结果，没有真实执行记录的系数固定1，不冒充历史优化策略。正式积累发布档案时可关闭该开关。研究与正式指标分别输出。

所有报告位于 `output`；每天输出HTML/Excel，按已有样本自然周、自然月输出完整明细。`candidate_comparison.csv`保存全部候选结果，`candidate_runs`保存回测证据，`adjustments/adjust_log.csv`及事务/备份目录保留调整轨迹。数据库损坏或丢失会报错并给出恢复说明，不会静默重建。

测试：`python -m unittest discover -s tests -v`。

历史表现不代表未来收益；调参建议需人工确认后生效。
