# 统一数据库版说明

本项目位于三模块套件中，数据来自 `../database/power_trading.sqlite`。优先使用根目录 main.py；数据更新方法见 `../database/数据库维护说明.md`。下文原独立版本的data文件均为自动恢复的兼容副本，不要直接维护。

# 套件版系数优化

安装requirements后执行 `python main.py`，全部设置来自config.yaml。当前默认2026-09-02历史研究，观测滞后6天；输入负荷优先读取 `../exchange/current_load/predict_YYYYMMDD.xlsx`。

模块包括：price_input.py（Excel/SQLite）、load_input.py（严格24点负荷）、price_prediction.py（双价格每日滚动模型）、coefficient_optimization.py（完整日场景CVaR及概率约束）、weather_features.py（历史预报及天气特征）。

新增可调模型插槽 `model_name: ridge / extra_trees`；ridge_alpha、t_base、use_weather、use_load_feature均实际进入模型。前置实际值至少2160个有效价格小时；默认90天场景，末30天验证，另留5天信息隔离，因此本例选系数期为55天。

k范围0.8—1.2，网格0.01，相邻变化≤0.05。价差定义日前减实时，正值倾向少买日前。保守收益为 `(Q-L)*(RT-DA)-abs(Q-L)*error_shrink*sigma-偏差费`；展示的价差向零折减。90%置信度对应经验超限比例≤10%。自动限额为训练场景中性策略日均收益绝对值的2倍，验证期固定，不用候选解反推。

独立验证按真实价格计收益，不用人为折减后的价格冒充结算价。默认偏差费率0是待完善研究参数，不代表正式结算考核为0。没有可行解时标记不可申报，研究模式采用列为1，不能认为1必然满足同一风险限额。

输出24点Excel、离线HTML、逐小时回测CSV、审计JSON，以及producer_YYYYMMDD.json发布快照。由review导入并生成后续调参建议。当前生产模式仍需要完整的发布时间与结算口径接口，不能仅改布尔开关解除。

完整串联、apply与rollback见套件根目录README。测试：`python -m unittest discover -s tests -v`。
