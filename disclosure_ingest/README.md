# 披露接入模块（M1迭代）

本模块把下载目录中的中调预测/实际披露ZIP及交易中心导出的单日预测XLSX接入共享数据库，原始文件保留在 `inputs/disclosure/`，数据库中保存来源哈希、快照、96点有效时间头审计、建模曲线点值和约束/检修等行级原始JSON。

## 运行

```bash
python disclosure_ingest/main.py
```

或在套件根目录运行：

```bash
python main.py disclosure
```

导入是幂等的：同一ZIP成员的SHA256已存在时跳过；不同来源版本可并存。预测数据按“目标日前一日12:00前可取得”的业务边界写入 `available_time`，但不把这个边界冒充精确发布时刻。实际披露的原始发布时刻未认证，只记录当前接收时间与证据说明。

日常建议不直接维护本目录，而是把五类交易文件放入根目录 `daily_inbox/`，运行 `python daily_import.py` 或双击 `一键日常导入并生成.bat`。

## 语义边界

- 96个有效时间头之外的空白列不算数据。
- 15分钟点保留原值；小时均值只在建模曲线表中生成，缺失时标记 `degraded_partial`，不补零。
- 约束、检修、必开停、断面等不逐格展开，保留一行一份原始JSON和上下文，避免把重复群成员行误当独立约束。
- 备用、条件阻塞和机组群约束的语义仍待来源认证，只作实验特征，不改称裕度或缺口。
