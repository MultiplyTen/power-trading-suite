# 统一数据库版说明

本项目位于三模块套件中，数据来自 `../database/power_trading.sqlite`。优先使用根目录 main.py；数据更新方法见 `../database/数据库维护说明.md`。下文原独立版本的data文件均为自动恢复的兼容副本，不要直接维护。

# 套件版负荷预测

安装本目录requirements后执行 `python main.py`。参数位于config.yaml；当前默认2026-09-02历史研究示例，历史观测滞后6天，与D+5实际回填及D−1发布时间对齐。

输出客户组合、各客户、全省负荷与原有双价格辅助预测，Excel和HTML位于output。run_manifest.json记录真实运行时刻、目标日期、配置快照、文件摘要及模型版本，供review入库。套件入口自动把24点组合负荷交给系数模块。

套件采用 `training.selection_mode: fixed`，确保回写参数实际生效。组合负荷模型参数在 `models.portfolio`：ridge_alpha、cooling_threshold、half_life_days、use_weather、name。name可为baseline_ridge、residual_zero；后者仅使用同类日衰减负荷基准，无回归残差。

输入CSV/Excel、客户地区映射、历史预报和真实可用时间的约束见config.yaml与SPECIFICATION.md；套件运行和调参流程以根目录README为准。原config.historical.yaml/config.backtest.yaml为原独立项目参考配置，默认入口不使用它们。

`python -m unittest discover -s tests -v`运行测试。研究结果不直接替代正式申报。
